# StockDekho - Live NSE Stock Tracker
Built by Aditya Yadav

🔗 Live Demo: https://yadavaditya1272-ship-it.github.io/stock-tracker/

### Why I built this
I wanted a simple way to track NSE shares without complicated apps like TradingView. 

### Features
- Live NSE/BSE prices (Real data from Yahoo Finance)
- Nifty 50 & Sensex live
- Watchlist + Search
- Profit & Loss calculator with brokerage
- Price alerts

### Tech Used
HTML, React, JavaScript, Tailwind CSS, Yahoo Finance API

### What I learned
- How to fetch live API data
- How to fix CORS error using proxy
- Making charts with SVG
